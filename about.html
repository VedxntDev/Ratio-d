About Ratio’d

Our Mission

Ratio’d was created to solve a pervasive problem: phishing, brand impersonation, and urgent financial scams target millions of users every day, yet traditional filters either fail to explain why a message was flagged or invasively log user correspondence to remote corporate servers.

Ratio’d delivers deterministic, explainable, and air-gapped threat detection. We sanitize and redact personal identifiable information (PII) directly in the browser before analyzing threats, empowering humans and automated AI agents to stay protected without sacrificing their privacy.

Technical Detection Architecture

Our detection engine combines multiple defensive layers:

  • Deterministic Rules: Zero-latency detection of cryptographic wallet drains, fake security notices, and credential harvesting patterns.
  • Homoglyph Defense: Neutralization of deceptive Cyrillic, Greek, and zero-width characters in domain names and URLs.
  • Levenshtein Brand Distance: Real-time distance scoring against major banking, retail, and tech domains to detect typosquatting.
  • VegaML Hamiltonian Physics: Energy-state and momentum models that distinguish legitimate marketing and promo newsletters from urgent coercive threats.
  • Safe Peek Unmasker: Safe redirect tracing following HTTP Location headers to reveal cloaked landing destinations.

Agent Protocols & Automation

Ratio’d is designed to be fully accessible to autonomous agents, LLMs, and security automation tools. We implement open machine protocols:

  • /llms.txt & /llms-full.txt — Plaintext LLM documentation standard
  • /openapi.json — OpenAPI 3.1.0 machine schema
  • /.well-known/mcp.json — Model Context Protocol (MCP) server manifest
  • /.well-known/agent.json — Agent-to-Agent (A2A) discovery card
  • /sitemap.xml — Complete machine-readable XML sitemap
