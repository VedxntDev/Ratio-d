AIR-GAPPED PRIVACY

Ratio'd — Privacy Policy

Effective Date: September 25, 2026

1. Zero Data Collection & Local PII Redaction

Ratio'd is built on a zero-knowledge, privacy-first architectural guarantee. All Personally Identifiable Information (PII)—including phone numbers, email addresses, and one-time verification passcodes (OTPs)—is redacted client-side directly inside browser memory before any telemetry or threat analysis occurs.

2. No Data Persistence or Storage

Ratio'd does not store, persist, sell, or share raw message text, email content, or personal communication logs. Zero user data is written to external cloud databases or log files.

3. Manifest V3 Compliance

Ratio'd operates strictly within Manifest V3 guidelines. No remote executable code is fetched or executed. All extension scripts run locally inside the installed extension bundle.
