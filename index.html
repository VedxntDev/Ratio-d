  1. Download the ZIP

    Use the button on the left. It saves to your normal Downloads folder.

  2. Unzip it

    Double-click ratiod-extension.zip. You should end up with a folder that contains manifest.json.

    Safari on macOS unzips automatically — skip to step 3. On Windows: right-click the ZIP → Extract All.

  3. Open the extensions page

    Copy the address below and paste it into your Chrome address bar.

    chrome://extensions

    Chrome blocks links to chrome:// pages from any website, which is why this one needs a copy-paste.

  4. Load it

    1. Turn on Developer mode with the toggle in the top-right corner.
    2. Click Load unpacked in the toolbar that appears.
    3. Pick the unzipped folder — the one containing manifest.json, not the ZIP file.

  5. Open Gmail and try it

    Click any email in your inbox and the verdict banner appears at the top of the message.

    Open Gmail ↗ Test in the console

If something goes wrong

"Load unpacked" is missing

Developer mode is not on yet. Toggle it in the top-right of the extensions page and the toolbar with Load unpacked appears.

Chrome says "Manifest file is missing or unreadable"

You picked the ZIP instead of the extracted folder. Go back, extract the archive, and choose the folder containing manifest.json.

The banner never appears in Gmail

Refresh Gmail once with Cmd+R (Windows: Ctrl+R) after loading, then open an email you have not already got open. The extension only runs on mail.google.com.

The banner shows "engine unreachable"

Rare — the extension talks to the live API automatically. Check your connection and reload the email. If you run the project locally, npm start and the banner will prefer that.

How do I remove it?

Open the extensions page, find Ratio’d, click Remove. Nothing was stored locally, so there is nothing to clean up.
